reduction, the transfer bookkeeping or the table bounds. But the certificate **as it was run is

## 1. The reduction

**1a. Coverage: SOUND.** The domain facts below were rederived independently, not taken from
NOTES.

- Saturation gives R <= 2. If R > 2, the empty circumcircle's centre is more than 2 from every
  centre, so a heptagon fits there.
- Non-overlap gives every edge >= 2u (inscribed discs), and R <= 2 gives every edge <= 4.
- An obtuse triangle has c^2 > a^2 + b^2 >= 2(2u)^2, so its longest edge is > 2u sqrt2.
- Every triangle with longest edge < 2u sqrt2 is therefore acute. The main sweep covers acute
  triangles with longest edge d in [2u, 4], so it covers all of these (sliver at d = 2u: FLAW-2).
- I rederived the main sweep's y >= 1.2. With x <= d/2, nonobtuse at c2 means
  y^2 >= x(d - x) >= x^2, and |c0c2| >= 2u means y^2 >= 4u^2 - x^2. So
  y^2 >= max(4u^2 - x^2, x^2) >= 2u^2, giving y >= 1.274.
- The obtuse sweep covers d in [2.548, 4]. Since 2.548 < 2u sqrt2 = 2.5483248, every triangle with
  longest edge >= 2u sqrt2 is in its domain, obtuse or not.
  - Its lower bound y >= 0.8 is valid: y = ab/(2R) >= ab/4 >= u^2 = 0.81174.
  - x in [0, 2]: c0c1 is longest, so the angles at c0 and c1 are acute, x in (0, d), and x <= d/2
    <= 2.
  - y <= d sqrt3/2 <= 3.4641 < 3.5.
  - Regions: `src/modal_obt.py:36-37`, `runs/sweepR.sh`, `runs/pilot_dl.sh`.
- No triangle in the main domain can receive. A donor's long edge is > 2u sqrt2 and is shared
  with the receiver, so the receiver's longest edge is >= 2u sqrt2. So D terms are 0 there and
  the main sweep needs no table.

**1b. Conservation: SOUND.**
- Proof-side transfer: D5(r_T, cos gamma_T) from each obtuse T. It is paid by the neighbour
  across T's longest edge and credited to T, so b* = b + D_out - sum D_in.
- The sweep subtracts `up(target + up(extra))` (`bnb2.py:422`), with
  extra = `inc_short - d_lb(r01, cg)` for a certainly obtuse box (`bnb2.py:343`).
  `d_lb` is a lower bound of D5 over the box, so this is an upper bound of D_in - D_out.
- A receiver is charged `dhat_ub(r, cos alpha)`, the max of D5 over r' in r and
  c in [-cos alpha.hi, 0] (`bnb2.py:306-315`).
- Delaunay gives alpha + gamma <= pi, so cos gamma >= -cos alpha. So the donor's actual
  (r, cos gamma) lies in the rectangle the receiver is charged for, and r is the same shared edge.
- Each D therefore enters once with + (as a lower bound on the donor side) and once with -
  (as an upper bound on the receiver side). This is the correct direction for both inequalities.
  The f transfers cancel because f o R = -f.
  - I checked algebraically that f = g - g o R + g o m - g o S (`bnb2.py:134`) satisfies
    f o R = -f and f o m = f, with R^2 = m^2 = id and m o R = S, S o R = m mod 2pi/7.
  - I rederived that the reversed edge's configuration is R(a, b) = (b + pi/7, a + pi/7). This
    uses -pi = pi/7 mod 2pi/7.
  - I rederived that the mirror image's ccw edge carries m(a, b) = (pi/7 - b, pi/7 - a).

**1c. Boundary at 2u sqrt2: SOUND.**
- `rb[0] - 2u sqrt2 = +2.748e-16` (mpmath, 50 digits).
- D5 rows 0 and 1 are exactly 0, so D5 = 0 for r <= rb[1].
- The column at c = 0 is also exactly 0, so D_out is continuous at the right angle.
- D5 >= 0 at all nodes, which justifies clamping lower bounds at 0 (`bnb2.py:322`).
- D5 <= D4 at every node. cb spans [-1, 0], rb spans [rb0, 4], and both grids are strictly
  increasing.

**1d. Edges charged: SOUND.**
- `inc_short` charges edges 12 and 20 on every box, using the correct opposite angles: at c0 for
  edge 12 and at c1 for edge 20 (`bnb2.py:336-339`).
- Edge 01 is charged as incoming unless the box is certainly obtuse, in which case nothing can
  arrive across it.
- `dhat_ub` returns 0 only when r.hi < rb0 (where D5 = 0) or cos alpha <= 0. In the second case
  alpha >= 90 deg, so the neighbour's gamma <= 90 deg and the neighbour is not a donor across
  this edge.
- NaN cannot reach `ca.hi > 0` (which would silently mean "no charge"). Every
  squared-length lower bound in `_cos_at` is >= 0.64 on the domain, so the denominator interval
  is strictly positive.

## 2. Rigour of bnb2

**2a. FLAW-1: half-widths are not outward-rounded.** `bnb2.py:203, 222, 368, 506` compute
h = (B[:,:,1] - B[:,:,0])/2, and `ctr_R` uses the float midpoint c = B.mean(2). The bounds
assume |x_k - c_k| <= h_k on the box.

- I checked this in exact rationals on 23,628 coordinates of real open boxes
  (`runs/sweep/w_open4_k39.npy`, `runs/sweepR/open_k38.npy`).
- The true half-width max(hi - c, c - lo) **exceeds h in 8,779 coordinates (37%)**, by up to
  2.2e-16.
- Effect: each first-order, second-order and dual lower bound can be too high by about
  sum_k |dphi/dx_k| x 2.2e-16. With the f_w030 coefficients (|c|_1 = 0.061, frequencies up to 14)
  and the multipliers, I estimate this at <= 1e-14 per box.
- That is far below the margins seen near the DL (around 1e-9 at the chart faces), but the
  certificate does not record per-box margins. So it cannot be shown harmless from the logs.
- The 1.5e-16 by which the float target exceeds the true acrit does not absorb it.
- **Fix:** `h = up(np.maximum(hi - c, c - lo))`, then re-run both sweeps, or log the minimum
  `lb - tg` over certified boxes and show it is > 1e-13.

Everything else outside `rig.py` checks out:
- E2 is a lower bound of 4u^2 (`:181`). The x <= d/2 test uses `dn` (`:188`). The R > 2 test
  r02 r12 > 16 y^2 is an interval comparison (`:189`).
- SAT gaps (`:174`) are float differences. Round-to-nearest preserves the sign of a - b, so the
  `< 0` and `>= 0` tests are exact.
- Multipliers `mu` are exact floats turned into point intervals. The heuristic choices
  (`_min_vertex`, `_cand_float`, the chart pre-filters) only decide which valid bound to try.
- Constants: PI7 and P7I are formed as PI*(1.0/7.0), which is not an exact 1/7. Checked in
  mpmath, they still enclose pi/7 and 2pi/7 (lo - exact = -4.6e-16 / -9.2e-16,
  hi - exact = +4.3e-16 / +8.5e-16). PIO2 and U_ enclose their values.
  The target 1.5326754446782214 exceeds the true acrit by 1.53e-16, which is the safe direction.

**2b. Bilinear table bound: SOUND (rederived).**
- On a cell the interpolant is multilinear, so its extremes over a sub-rectangle are at the 4
  corners.
- The cell visit test is closed (`:291, :296`), so cells cover the clipped rectangle.
- Float error:
  - r - rb_i and rb_{i+1} - rb_i are exact by Sterbenz, since r is in [2.5, 4].
  - The c-differences have absolute error <= 3.5e-18 and the cell widths are exact.
  - So t and s are off by <= ~2e-16, which moves the value by <= 0.234 x 4e-16.
  - The 4-term bilinear sum with nodes <= 0.234 adds <= ~3e-16.
  - Total < 1e-15, against a pad of 1e-12. **The pad covers it by more than 1000x.**
- Clipping r to rb0 in `d_lb` is valid only because D5 = 0 near rb0. That holds (1c).

**2c. Pruning: SOUND.**
- Every discard is one of:
  - an interval-certain geometric violation (edge < 2u, c0c1 not longest, x > d/2, R > 2, or
    obtuse in main mode);
  - SAT overlap on the whole box (complete with both polygons' edge normals);
  - a lower bound >= target;
  - chart exclusion.
- Dual v1 (`:367`) uses an axis that is the only one whose gap can still be >= 0. Feasibility
  then forces that gap >= 0, which forces h >= 0 for every vertex of the other polygon. Valid.
- Dual v2 (`:505`): vertex strictly inside the other 6 half-planes on the whole box, so h < 0
  would put it in the interior of the owner. Valid.
- Taylor form (`:208-217`): the diagonal uses 1/2 min(H_ii, 0) h^2 and the off-diagonal uses
  -|H_ij| h_i h_j with i < j, which is the right factor. AD rules checked by hand: product,
  chain rule, the second derivatives of atan, sqrt, inv and sin/cos, and the cross terms.
- Stuck boxes are counted and dropped, but every slice in both sweeps reports `stuck: 0`.

**2d. Right-angle split: SOUND.**
- `certain_obt = cg.hi < 0` and `certain_non = cg.lo >= 0`.
- A straddling box takes the max of the obtuse-part bound (cg clipped to <= 0) and the
  non-obtuse-part bound (cg clipped to >= 0) (`:340-345`).
- At cg = 0 exactly: no outgoing transfer (not obtuse), and no incoming one across 01
  (`ca.hi > 0` fails). This is correct, and consistent with D5(., 0) = 0.

**2e. Canonicalisation: SOUND.**
- Rigid motions: b depends only on relative orientations t - phi, and area is invariant.
- Cyclic relabelling: b is a sum over ccw edges.
- Mirror: f o m = f (1b), and D5 is geometric.
- 7-fold symmetry: f is 2pi/7-periodic in a and b through cos(7a), and the heptagon is
  invariant.
- Edge directions in `b_A` (`:144-146`) match atan2 for x in [0, d/2] and y > 0.
- The chart's DL labelling (P0, P1, P2) = (H2p2, H0, Ht1) is a cyclic shift of the arb frame's
  (H0, Ht1, H2p2), so it gives the same edge set.
- No tight point is lost: the DL triangle is scalene (x = 0.8896 < d/2), so its canonical point
  is unique. A second canonical point with b = acrit outside the charts would have made the DL
  slice impossible to finish.

**2f. Slice partition.**
- t0 is contiguous in both sweeps. Consecutive slices use the identical float expression for
  hi_k and lo_{k+1}. Main: [0, 0.897598] (awk rounding gives an upper end above 2pi/7, which is
  fine). Obtuse: [0, 0.8975979010256552]. All main-sweep regions were checked from the final
  JSON lines; all Modal regions from the logs.
- **FLAW-2: three uncovered slivers.**
  1. The upper bound 0.8975979010256552 used for t1 and t2 in both sweeps, and for t0 in obtuse
     slice 44, is **below 2pi/7 by 3.5e-17**. So orientations in (fl(2pi/7), 2pi/7) are not
     covered, and neither are their 2pi/7-translates just below 0.
  2. The main sweep's lower bound d = 1.8019377358048383 is **above 2u by 4.0e-17**.
- The d sliver is harmless but needs a sentence in the proof. Three pairwise distances
  < 2u + 4e-17 would need three pairwise edge-to-edge (point-reflected) contacts, which is
  impossible: two of the three would be translates.
- The orientation sliver needs either a re-run with outward bounds (for example
  t in [-1e-12, 2pi/7 + 1e-12]), or a closure lemma. The closure lemma would argue that b - acrit
  - (charge bound) is continuous (it is, because D5 = 0 at c = 0 and for r <= rb1) and that every
  feasible sliver point is a limit of feasible covered points. I would not rely on the second
  claim without a proof; jammed configurations make it non-obvious.

**2g. rig.py: SOUND.** I wrote an independent stress test against mpmath at 40 digits. It
covered:
- 5,000 random cos/sin intervals in [-40, 40] with widths from 1e-16 to 4, including intervals
  that straddle k pi/2 and k pi by 1e-15;
- 3,004 atan intervals on [1e-12, 1e3], including t = 1 +/- 1 ulp;
- 3,000 each of add, sub, mul, inv and sqrt.

There were **0 failures**. I also checked the `dn`/`up` argument: |a| 2^-51 >= 2 ulp(a), so the
rounded result lands below the exact value; 2^-1000 covers zero and subnormals.

One fragile point: the Taylor coefficients `(-1)^k/_FACT[2k+1]` are enclosed as the float
quotient, not the true 1/(2k+1)!. This is sound only because each operation's widening (>= 2 ulp)
has more than enough slack: the coefficient error is about 1e-41 against a widening of about
1e-16. Worth a line in the proof, or use exact rationals.

**2h. Chart lemma and exclusion (`local_tube_arb.py`, `chart_excl.py`).**
- **FLAW-3.** `eta = (1-Q)*rho` (`local_tube_arb.py:119`) ignores the offset
  off = |Phi(z_c) - (0, s_c)| that the code itself computes (`:72-74`). Banach existence for
  targets in D_c needs |t - Phi(z_c)| <= (1-q) rho, so it needs eta <= (1-q) rho - off.
  In addition, `chart_excl` centres the s-window at v.z_c rather than at s_c.
  - The recorded `tiny` (= 4 off) is at most 2.7e-17, so the gap is about 7e-18. It is formal,
    not numerical.
  - The 2^6 sub-box centres and radii are also formed in floats, so their union might miss
    1e-21 seams.
  - Fix: eta = dn((1-q) rho - off), and build the sub-boxes from exact endpoints.
- **UNCLEAR-3.** The docstring's per-chart conclusion b >= m_c is **negative for 2 charts**
  (`excess_lower` = -2.5e-10 in both `charts_w030.json` and `charts_w030b.json`), yet
  `chart_excl` uses every chart with `ok = True`. The tube is still sound by the global
  argument in NOTES:
  - beta'' >= B2 > 0 on each chart (min B2 = 0.0135);
  - consecutive s-windows overlap (largest gap -6.4e-5, i.e. an overlap);
  - so beta is convex on [-0.0301, +0.0500], and beta'(0) = 0 exactly by exactification, which
    gives beta >= beta(0) = acrit.
  - Then w_k > 0 (min 1.7e-4) carries the bound from the contact curve to each D_c.

  So the written proof must use the convexity argument, not m_c.

  I checked the remaining chart facts:
  - All charts have q < 0.033 and every half-plane max is < -0.159, so condition (A) holds.
  - `charts_w030*.json` are identical to the JSON lines of `runs/tube_w030*.log`.
  - Recomputing the exactification for `f_w030.npy` in arb gives
    mu = [-1.168485374e-12 +/- 1.9e-22] on basis index 9. That is inside the B&B's `HEPT_MU`
    interval [-1.1684855e-12, -1.1684853e-12], and index 9 is bnb2's default `mu_idx`.
  - `FArb` and `FTrans` use the same basis order (Chebyshev k, then [1, cos, sin, cos 2, sin 2]
    in a and in b) and the same antisymmetrisation. So the chart lemma and the B&B are about the
    same f.

## 5. Lemmas L1-L6 and what a human proof must still supply

**The computation discharges L4 only.** That is the per-triangle inequality b*(T) >= acrit for
every triangle with edges in [2u, 4] and R <= 2, modulo FLAW-1 to FLAW-3. Everything else is
stated in NOTES but not proved.

- **L1 (saturation): stated, not proved.** Needed:
  - the definition of density (limsup over growing windows);
  - the lemma that a packing can be saturated without lowering its upper density.

  Both are standard; cite or write them.
- **L2 (Delaunay facts): stated, not proved.** Needed:
  - existence and local finiteness of the Delaunay triangulation for a Delone set (the centres
    are 2u-separated, and saturation makes them 4-dense);
  - R <= 2;
  - edges in [2u, 4];
  - opposite angles summing to <= pi, including in degenerate cocircular cells triangulated
    arbitrarily (sum = pi there).
- **L3 (bookkeeping): partly stated, not proved.** Needed:
  - every obtuse triangle has a unique longest edge, > 2u sqrt2, and a unique neighbour across
    it;
  - that neighbour's opposite angle alpha satisfies cos gamma >= -cos alpha;
  - the transfer amount is the exact function D5 (bilinear on the float nodes in
    `runs/D5_nodes.npy` / `D5_bins.json`, and 0 for r < rb0), so both sides use one
    well-defined number.

  The NOTES remark about chains being "absorbed by the recursion over r", and the D2
  construction, are irrelevant to soundness and should be dropped from the proof: the sweep
  charges all three edges directly.
- **L4: discharged by the two sweeps plus the chart lemma.** The written proof still needs:
  - the domain-reduction facts 1-7 of NOTES as lemmas (I rederived all of them above; they
    hold);
  - the symmetry identities f o R = -f and f o m = f, and the 2pi/7-periodicity;
